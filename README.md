# MixedSignals

MixedSignals is a modular video effects project focused on datamoshing workflows.

The first milestone is a browser-based prototype that shows the user flow and interface structure. The reusable video processing core and native apps will be added later.

## Development

Install dependencies:

```bash
pnpm install
```

Start the website:

```bash
pnpm dev
```

Build the project:

```bash
pnpm build
```
