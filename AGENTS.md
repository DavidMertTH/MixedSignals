## Hard Rules

- All code identifiers, file names, folder names, UI labels, ARIA labels, user-facing errors, and website copy must be in English.
- Do not add code comments.
- Keep code modular, object-oriented where it improves ownership, and free of god classes.
- Prefer small components, small services, and explicit types.
- Use feature branches for all work.
- Keep commit messages short.
- Run `pnpm build` before committing frontend changes.
